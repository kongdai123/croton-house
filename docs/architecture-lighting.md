# Lighting architecture: from patches to a model

Status: proposal (2026-10-17). Inputs: [postmortem](audit/postmortem.md), [lighting roles](audit/lighting-roles.md),
[spatial data](audit/spatial-data.md), [shader stack](audit/shader-stack.md), [verification](audit/verification.md).

## Why

One week, 18 lighting bugs, almost all found by walking the site. The audits show the cause is structural:

- **108 decisions** about how an object is lit, made by ~75 mechanisms in ~33 files: name regexes ("is it a plant" six
  ways, "is it glass" four ways), id strings, coordinates.
- **Five hand-typed room tables** and a twelve-times-pasted "inside the house" rectangle that disagree by up to 0.76 m;
  the garage exists only as constants.
- **~10 shader features spliced into three.js by text replacement**, order-dependent, one already a silent no-op
  (merged mirror roughness), sampler costs only partly budgeted.
- **No automatic verification**: nothing runs on push, no test builds the real house, no bake statistics, no renders.

## Principles

1. **Declared, not inferred.** Objects and materials declare their lighting role; code never keys behaviour on names,
   ids or coordinates.
2. **One source of truth per fact**, read by the site, the export and the bake (JS and Python readers, same tests).
3. **One owner per piece of state.** Derived things (mirror clones, baked copies, probe volumes) subscribe to the owner.
4. **Fix the class.** A bug closes with a root cause, a class fix and a check that would have caught it.
5. **Gates before eyes.** Nothing reaches the owner without passing the gates below.

## The four parts

### 1. Plan model: `web/data/plan.json`
Generated by `build_plan.mjs` from the Zillow import (`house.json`) plus a small hand-authored overlay for what Zillow
lacks (annex, closets, outdoor zones). Holds: one coordinate frame and `toScene`; levels (ceiling, door, sill, head);
the exterior outline; **spaces** (id, kind, zone, bilingual label, polygon, ceiling, lamp groups, reflection-probe
seeds, indoor weight) including the garage annex and outdoor zones; **walls** (annex included); **openings** (type,
hinge, swing, sill/head, and the two spaces they connect); patches (niche, window overrides); the probe-volume grid.
Readers `web/src/plan.js` and `bake/scripts/plan.py` share one API (`spaceAt`, `isInside`, `insideGLSL`,
`indoorWeight`, `wallsAt`, `neighbors`, `toScene`) and one golden test file.
Replaces: rooms.js, both `ROOMS` tables, `ANNEX`, house.js annex constants, the minimap/ui garage rects, all twelve
inside rectangles, `VOL`, the probe-wall sources, door type tables.

### 2. Lighting manifest: `userData.lighting` (also exported to glTF extras)
Per object: `role` (architecture, furniture, plant, ground, glass, cloth, mirror, emitter, door, movable, presentation)
with presets so most objects declare only the role; `bake` (lightmap / probe / none), `motion` + still parts,
`probeSide`, `sun` (cast/receive/track), `space` (from the plan), `group`. Per material: `surface` (opaque, foliage,
leafCard, sheer, glass, mirror, screen, lamp, indicator, fire), `alphaCutout` (separate from "plant"), `emits` (kind,
strength, switched), `wet`, `reflection`. Per fixture: switch, space, exterior, default per slot, light spec (bake/live),
switch plate. **One classifier** fills defaults and validates; export, unwrap, bake, lamp groups and runtime only read
it. Lamp groups come from fixture `space` + `kind`, not room boxes.

### 3. One composed baked shader
Role-based feature flags; a pure `samplerPlan()` fixes flags within the device's texture units before generation; a
pure `compose()` emits the shader once from chunk files (one world-position varying, one probe fetch, region-aware probe
sampling from the plan); the cache key derives from the flags. The contact, puddle and TAA wrappers become flags.
A node test resolves every role x flag combination (declarations, sampler count, unique keys); a SwiftShader browser
test links them.

### 4. Gates
| Gate | What | When | Cost |
|---|---|---|---|
| 0 | test runner, `eslint no-undef`, tests in CI before deploy | every commit / push | seconds |
| a | headless scene invariants: real house + layout + switches built in node; every space lit and switched, encoding matches groups, probes never cross walls or the outline, sampler budget per material, closed doors block, switch state survives quality change, mirror clones follow slots | pre-push, CI | ~10 s |
| b | bake QA: per-unit coverage/black/hole stats, tier bleed, lamp/probe/reflection sanity, diff vs approved baseline | after every bake | minutes |
| c | render regression: cameras per space x 4 slots (+ known-bad spots) vs Cycles and vs last approved, on a GPU node | after bake or lighting/shader change | ~15 min |
| d | UI smoke: tour, switches, doors, sliders, quality, slots (Playwright asserting) | pre-push for UI changes | ~2 min |

## Migration (each step behaviour-preserving unless stated, each with its gate)

1. **Gates 0 + characterisation**: test runner, lint, CI; golden captures of today's classifications (every object's
   role, group, space; shader text per material class) so refactors prove they change nothing unintended.
2. **Plan model**: build `plan.json` + readers; golden-equivalence tests sample every old classifier on a 5 cm grid;
   swap runtime consumers first.
3. **Lighting manifest**: classifier + presets; migrate decision points file by file against the goldens; delete the
   regexes.
4. **Composed shader**: chunks unchanged first, then probe path, sampler plan, lightmapped path, wrappers to flags.
   Fix the mirror-roughness no-op; delete dead TAA or wire it properly.
5. **Gate a, b, c, d** in full.
6. **Bake-affecting switch-over** (lamp groups from the manifest, reflection layout and probe walls from the plan,
   unwrap density) and **one rebake**, validated by gates b and c before the owner sees it.

## Decisions (owner, 2026-10-17)
- Room shapes: keep the current, as-built room shapes from `house.json`; the other tables conform to it (office/dining
  split at the plan's wall, ~x 1.12; the primary vestibule nub belongs to the primary bedroom; bedroom B's south edge
  from the plan).
- The hall and the hall closet are their own spaces, each with its own lights and switch.
- TAA: keep the code (wire it through the composed shader's flags rather than delete it).
- Every closet and the laundry nook gets a ceiling light on its own switch (rule, enforced by the
  rooms-have-switched-light invariant over every plan space), not added piecemeal.
- The outline's porch-side face (garage block inner vs outer face) is corrected in the bake-affecting step.
